ELEGANT MIDDLE EAST — WEBSITE FILES
====================================

UPLOAD
------
Upload EVERYTHING in this folder into public_html on GoDaddy
(cPanel > File Manager). Do not upload the enclosing folder itself —
index.html must sit directly inside public_html.

  index.html          Home
  divisions.html      Divisions
  work.html           Selected work
  about.html          About
  contact.html        Contact
  SiteHeader.dc.html  Shared header  (required — do not rename)
  SiteFooter.dc.html  Shared footer  (required — do not rename)
  support.js          Page runtime   (required)
  motion.js           Scroll animations
  assets/             Photos, logos, hero video, favicon

CONTACT FORM
------------
Live. Enquiries are delivered to info@elegantmena.com via Web3Forms
(free tier: 250 submissions/month). The access key is already in
contact.html. If enquiries ever stop arriving, check the Web3Forms
dashboard and your spam folder first.

AFTER UPLOAD
------------
- Ask GoDaddy support to switch on the free SSL certificate so the
  site loads over https.
- If you change a file later and the old version still shows, do a
  hard refresh (Ctrl+Shift+R / Cmd+Shift+R).

NOTES
-----
- Both languages are built in; the عربي button in the header switches.
- Total size is about 8 MB, most of it assets/hero.mp4.
